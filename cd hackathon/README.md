
# Interpreter vs Compiler Profiler

## Project Description

This project compares an interpreter and a compiler using a custom mini-language.

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript

## Main Features

1. Lexical Analysis
2. Parsing
3. Direct Interpretation
4. Intermediate Code Generation
5. Virtual Machine Execution
6. Execution Time Measurement
7. Instruction Count
8. Performance Comparison Dashboard

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Create a virtual environment.

   py -m venv .venv

4. Activate the environment.

   .venv\Scripts\Activate.ps1

5. Install dependencies.

   python -m pip install -r requirements.txt

6. Run the application.

   python app.py

7. Open http://127.0.0.1:5000 in your browser.

## Supported Language Features

- Variables

- Conditional statements
- If and else
- While loops
